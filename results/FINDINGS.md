## Caveats

- **Harness and model are confounded.** Every pair difference may come from the harness, the model or both; the tier claim only infers that the difference tracks whether the harness hands the model its exact model ID.
  *Claims: [not-portable-tier](claims.md#not-portable-tier), [model-version-codex](claims.md#model-version-codex)*
- **Tier is an assumed scale for the Claude pair.** Its tier results mean consistent with the chosen scale, not knows its rank. Only the Codex pair's tier is documented.
  *Claims: [tier-claude-correct](claims.md#tier-claude-correct), [gate-tier-keeps-opus-sonnet-out](claims.md#gate-tier-keeps-opus-sonnet-out), [select-tier-claude-correct](claims.md#select-tier-claude-correct), [tier-codex-incorrect](claims.md#tier-codex-incorrect)*
- **Two reps per cell.** One run flips a cell's rate by half, so only whole-cell differences count.
  *Claims: [delivery-no-whole-cell-difference-once-loaded](claims.md#delivery-no-whole-cell-difference-once-loaded)*
- **The flagship guidance branch is the default.** With no skill every subject wrote no docstring and no tests, so only branches that prescribe tests are credited.
  *Claims: [baseline-default-is-flagship-branch](claims.md#baseline-default-is-flagship-branch), [work-adding-branches-changed-behaviour](claims.md#work-adding-branches-changed-behaviour)*
- **Haiku's loading failure dominates its Study 3 results.** Its gate and selection numbers say more about discovery than about the condition.
  *Claims: [haiku-loading-limits-gates](claims.md#haiku-loading-limits-gates), [haiku-skips-feature-skills-natively](claims.md#haiku-skips-feature-skills-natively)*
- **The Codex pair's session ground truth is inferred from the runs it scores.** Its partial delegation result is circular in the way the design names.
  *Claims: [capability-from-tools-codex-partial](claims.md#capability-from-tools-codex-partial)*
- **The Codex pair's ability to enter a gated skill written for it is untested.** It is included only under the tier gate, which its self-placement defeats.
  *Claims: [gate-tier-codex-refuses-own-skill](claims.md#gate-tier-codex-refuses-own-skill), [included-loading](claims.md#included-loading)*
- **Web search can replace self-knowledge.** The Codex pair's only non-flagship tier answers came from runs that searched OpenAI's documentation.
  *Claims: [tier-codex-varies](claims.md#tier-codex-varies)*
- **Batches and reruns.** Runs were made on 2026-09-22, 2026-09-23 and 2026-09-24; the Codex pair's `harness-stamp` and selection runs were rerun after turn failures.
  *Claims: [capability-from-knowledge-codex](claims.md#capability-from-knowledge-codex), [select-vendor-correct](claims.md#select-vendor-correct)*
- **Token counts include cached input** and the harnesses' tool sets differ, so cross-pair cost comparisons are indicative only.
  *Claims: [skill-overhead-tokens](claims.md#skill-overhead-tokens), [skill-overhead-tool-invocations](claims.md#skill-overhead-tool-invocations)*
